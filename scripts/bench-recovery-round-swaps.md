# 一般紅0／A2整局互換比較

2026-10-25，Codex。保留功能：兩模式改善都超過 0.05 局。

比較指令：設定 NODE_PATH 後執行 `node scripts/bench-recovery-round-swaps.cjs <輸出JSON路徑>`。baseline 只移除整局互換呼叫，其他程式一致；每個種子開獨立無痕頁面，交錯執行前後版本。初次比較先以 HTTP 注入相同函式，確認門檻後才接入正式程式；下表是該次實測。

設定：紅0、A2各12種子；回復上限4.5；三條關、末張9關；莊閒差距、和局、四張比例、特殊局及4／5／6張上下限留白；未選目標路單、混色關。每副最多60秒／100次候選。平均回復以416切點的原分析器未四捨五入數值計算。
